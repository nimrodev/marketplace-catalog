The Commons Catalog

A static visual mockup for the neighborhood listings catalog — contributors post secondhand goods, moderators review before anything goes live. This page shows the intended look for the catalog grid, filters, item detail, and moderation queue, plus the token palette that MAR-36 will implement in code.

How to read this page. Every section below is a static snapshot — nothing here is wired to the API or interactive. Filter states, badges, and theme panels that would normally toggle are instead shown side by side so every state is visible at once. Field names and enum values match packages/shared exactly.
